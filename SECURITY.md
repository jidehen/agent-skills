# Security

Treat downloaded skill instructions and executable scripts as code: read them before use and run them with permissions appropriate to your project. RDF Agent Memory processes local files; source documents and candidate handoffs are untrusted input, and their text is evidence rather than instructions to the agent.

Keep private corpora, renditions, memory, and handoffs outside the public repository. Do not put secrets or confidential source excerpts into public issues.

If you find a vulnerability, use the repository's private vulnerability reporting feature when available. If it is unavailable, open an issue requesting a private contact without posting exploit details or sensitive data. Include the affected version and a synthetic reproducer when a private reporting channel is established.

The current collection is a prototype with no guaranteed response time or supported-version policy. Fixes and known limitations will be documented in repository changes.
